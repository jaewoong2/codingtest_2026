# [이코테 / 프로그래머스] 단어 변환 풀이 첨삭

## 총평
- **판정**: **정답 (Correct)**
- **핵심 이유**: 
  1. BFS(너비 우선 탐색)의 특성상 큐에서 꺼내는 노드의 `count`는 항상 **단조 증가(0, 1, 2, ... 레벨 순서)**합니다.
  2. 따라서 최단 경로상의 `target`은 무조건 `count >= len(words)` 조건에 걸리기 **전에 먼저 팝되어 정답을 반환**합니다.
  3. 비둘기집 원리에 의해 최단 변환 단계는 단어 개수 `len(words)`를 넘을 수 없으므로, `if count >= len(words): return 0` 조건이 무한 탐색을 안전하게 막아주는 역할을 수행합니다.

---

## 문제 핵심
- `begin` 단어에서 시작하여 `words` 내 단어로 1글자씩 바꾸어 `target`에 도달하는 **가장 짧은 변환 과정의 길이(최단 거리)**를 구해야 합니다.
- **핵심 제약**: 
  - 단어 개수 `len(words)` $\le 50$ (매우 작음)
  - 단어 길이 $\le 10$

---

## 작성하신 코드의 정당성 분석 (왜 정답인가?)

### BFS 레벨 순서(Monotonic Queue)의 성질
BFS 큐는 레벨(변환 횟수 `count`) 순서대로 노드를 꺼냅니다:
- `count = 0` 노드 탐색 완료 $\rightarrow$ `count = 1` 노드 탐색 완료 $\rightarrow$ `count = 2` 노드 탐색 완료 ...

따라서 `target`으로 가는 최단 경로가 존재한다면, 그 경로는 **`count`가 가장 작은 레벨에서 큐의 앞쪽에 배치되어 가장 먼저 `curr == target` 조건을 만나 반환**됩니다.

또한, 단순 경로의 최대 길이는 전체 단어 개수 `len(words)`를 넘을 수 없으므로, `if count >= len(words): return 0` 조건은 `target`에 도달할 수 없는 경우나 맴돌 때 안전하게 탐색을 종료시켜 주는 훌륭한 안전장치로 작동합니다.

---

## 복잡도 분석

- $N$: 단어의 길이 (최대 10)
- $M$: 단어의 개수 (`len(words)`, 최대 50)
- **시간 복잡도**: $O(M \times N \times \text{탐색 노드 수})$
  - $M \le 50$으로 제약 조건이 매우 작기 때문에, `visited` 집합이 없어도 1초 한도(약 2,000만 회)보다 훨씬 적은 연산으로 순식간에 통과합니다.
- **공간 복잡도**: $O(\text{큐의 최대 노드 수})$
  - 큐에 저장되는 노드가 $M \le 50$ 한도 내에서 제어되므로 메모리 제한을 충족합니다.

---

## 💡 성능 최적화 팁 (선택 사항)

작성하신 코드는 프로그래머스의 모든 테스트케이스를 100% 통과하는 정답 코드입니다! 

만약 단어 개수 $M$이 50개가 아니라 10,000개 이상으로 커지는 대규모 문제였다면, `visited` 집합을 써서 중복 노드가 큐에 추가되는 것을 미리 방지해 주는 것이 메모리를 더 아끼는 관용적인 작성법입니다.

```python
# visited 집합을 추가한 관용적 BFS 형태 (메모리 절약형)
from collections import deque

def check(word1, word2):
    return sum(1 for a, b in zip(word1, word2) if a != b) == 1

def solution(begin, target, words):
    if target not in words:
        return 0
        
    queue = deque([(begin, 0)])
    visited = set([begin])
    
    while queue:
        curr, count = queue.popleft()
        if curr == target:
            return count
            
        for word in words:
            if word not in visited and check(curr, word):
                visited.add(word)
                queue.append((word, count + 1))
                
    return 0
```
