# [이코테 / BOJ 14502] 연구소 풀이 첨삭

## 총평

- **판정**: 정답
- **핵심 이유**: 빈칸 중 세 곳을 고르는 모든 조합을 확인하고, 각 조합에서 바이러스가 도달할 수 있는 모든 빈칸을 확산시킨 후 안전 영역을 세고 있습니다. 가능한 벽 배치를 빠짐없이 확인하므로 최댓값이 보장됩니다.

## 문제 핵심

- `N x M` 격자에서 0은 빈칸, 1은 벽, 2는 바이러스입니다.
- 빈칸에 벽을 **정확히 3개** 세운 뒤, 바이러스는 상하좌우의 빈칸으로 퍼집니다.
- 바이러스 확산 후에도 0인 칸의 최대 개수를 구합니다.
- 표준 제약은 `3 <= N, M <= 8`이므로 빈칸 세 곳의 모든 조합을 시도할 수 있습니다.

## 현재 접근법

1. 입력을 받으며 빈칸과 초기 바이러스 위치를 따로 저장합니다.
2. 빈칸 목록에서 3개를 고르는 모든 조합을 만듭니다.
3. 각 조합마다 원본 격자를 복사하고 벽을 세웁니다.
4. 모든 초기 바이러스 위치에서 DFS를 실행해 연결된 빈칸을 2로 바꿉니다.
5. 남은 0의 개수로 안전 영역을 구하고 최댓값을 갱신합니다.

## 정확성 및 반례

반례를 발견하지 못했습니다.

- `combination()`은 선택한 인덱스 다음부터만 재귀호출하므로, 서로 다른 빈칸 3개의 모든 조합을 중복 없이 만듭니다.
- 각 조합에서 사용하는 `current_maps`는 행마다 복사한 새 2차원 리스트이므로, 바이러스 확산이 다음 벽 조합에 영향을 주지 않습니다.
- `move_virus()`는 0을 발견하는 즉시 2로 바꾸므로 같은 칸을 재방문하지 않고, 바이러스가 도달 가능한 모든 빈칸을 정확히 표시합니다.
- 따라서 각 벽 조합의 안전 영역이 정확히 계산되고, 모든 조합의 최댓값이 전체 정답입니다.

## 복잡도

`E`를 초기 빈칸 수, `N x M`을 연구소 크기라고 하겠습니다.

- 벽 조합은 `C(E, 3)`개입니다.
- 각 조합마다 격자 복사, 바이러스 확산, 안전 영역 계산이 각각 최대 `N x M`칸을 다룹니다.
- **시간 복잡도**: `O(C(E, 3) x N x M)`
- **공간 복잡도**: 모든 조합을 리스트에 저장하므로 `O(C(E, 3) + N x M)`. DFS 최대 재귀 깊이는 `N x M <= 64`라 제출 환경의 재귀 한도에도 문제가 없습니다.

빈칸이 64개라고 보수적으로 잡아도 `C(64, 3) = 41,664`개의 조합만 확인하므로 표준 제약 안에서 통과 가능한 규모입니다.

없습니다.

## 선택적 개선

- `combination()`이 모든 조합을 메모리에 저장하지 않고 하나씩 반환하게 만들거나, 표준 라이브러리의 `itertools.combinations(empties, 3)`를 사용하면 추가 메모리를 줄일 수 있습니다.
- `find_build_wall()`은 `combination(candidates, 3)`만 다시 호출하므로 없애도 의미가 바뀌지 않습니다.
- `destory_wall()`은 사용되지 않습니다. 남긴다면 철자를 `destroy_wall`로 바꾸고, 현재처럼 복사본을 사용한다면 함께 제거해도 됩니다.
- 제출용 코드에서는 로컬 `input.txt`를 자동으로 여는 7~10번 줄을 제거하면 표준 입력으로 테스트하기 더 쉽습니다.

## 실행 검증

- 저장된 예시 입력의 **실제 출력은 `27`**로 기대값과 일치했습니다.
- 3x3~5x5 무작위 격자 120건을 독립적인 `조합 + BFS` 기준 풀이와 교차 검증했고 모두 일치했습니다.
- 위 테스트는 정확성의 보조 근거이며, 모든 입력에 대한 판정은 조합의 완전성과 DFS 방문 논리로 확정했습니다.

## 이 문제에서 읽어야 할 신호

- **“벽 3개를 세운다” + 격자가 최대 8x8** → 빈칸 3개의 모든 조합을 시도하는 완전 탐색
- **“상하좌우로 퍼진다”** → 격자를 그래프로 보고 DFS 또는 BFS로 연결 영역 탐색
- **“안전 영역의 최대”** → 각 벽 배치를 시뮬레이션하고 최댓값 갱신
