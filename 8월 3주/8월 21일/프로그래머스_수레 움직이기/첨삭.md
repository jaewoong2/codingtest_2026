## 총평

- 판정: **오답**
- 핵심 이유: 
  1. 두 수레를 "동시에" 이동시키지 않고 `turn`을 번갈아 1개씩 넘기는 방식으로 인해 충돌/스왑 판정과 턴 관리가 구조적으로 왜곡되었습니다.
  2. `dfs(..., "BLUE", ...)` 재호출 전 `visited` 배열을 `inf`로 리셋할 때 시작점(0)을 재설정하지 않아 `visited`가 모두 `inf`로 남아 방문 체크가 무력화되어 **무한 재귀(`RecursionError`)**가 발생합니다.
  3. 백트래킹 과정에서 `continue` 조건문 이전에 `visited`를 복원하지 않아 방문 기록이 오염됩니다.
  4. 파란 수레가 빨간 수레의 이전 위치(`prev_red`)로 진입하는 것을 무조건 막아, **"빨간 수레가 지나간 자리를 파란 수레가 뒤따라가는 정상적인 이동(꼬리물기)"**까지 차단하여 답이 존재하는 경우에도 `0`을 반환합니다.

---

## 문제 핵심

1. **격자 크기**: $N \times M$ ($2 \le N, M \le 4$, 최대 16칸으로 매우 작음).
2. **이동 규칙**:
   - 매 턴마다 두 수레를 **동시에** 상하좌우 인접한 칸으로 1칸씩 이동시킵니다.
   - 단, **이미 자신의 도착 칸에 도착한 수레는 더 이상 이동하지 않고 해당 칸에 고정**됩니다.
3. **제약 조건**:
   - 벽(5) 및 격자 밖 이동 불가.
   - 자신이 **이미 방문했던 칸 재방문 불가** (도착 칸에 도달한 수레의 칸도 계속 방문 상태 유지).
   - **동일 칸 동시 이동 불가**: 같은 턴에 두 수레가 같은 좌표로 이동할 수 없습니다.
   - **크로스(자리 바꾸기) 불가**: 빨간 수레가 $A \to B$로 가고 파란 수레가 동시에 $B \to A$로 교차 이동할 수 없습니다.
4. **목표**: 두 수레가 모두 각자의 목적지에 도달하는 **최소 턴 수** (도달 불가능 시 0).

---

## 현재 접근법 분석

### 1. 턴 교대 DFS (`turn == 'RED' -> 'BLUE'`)
- 빨강 1칸 이동 $\to$ 재귀로 파랑 1칸 이동 $\to$ 재귀로 빨강 1칸 이동... 순으로 1개씩 번갈아 이동을 시도했습니다.
- 어느 한쪽이 먼저 도착하면 해당 턴을 건너뛰고 반대쪽 수레로 재귀를 넘겼습니다.

### 2. 거리 기반 방문 배열 (`visited[turn][r][c]`)
- 초기값을 `float('inf')`로 채우고, `visited[turn][nr][nc] < visited[turn][row][col] + 1` 조건으로 방문 여부를 판단했습니다.

---

## 정확성 및 오류 원인 분석

### 1. `RecursionError`의 원인: 시작점 미초기화
- 코드 하단에서:
  ```python
  dfs(r, b, "RED", r, b)

  visited["RED"] = [[float("inf") for _ in range(m)] for _ in range(n)]
  visited["BLUE"] = [[float("inf") for _ in range(m)] for _ in range(n)]

  dfs(r, b, "BLUE", r, b)
```
- 두 번째 `dfs(r, b, "BLUE", ...)`를 호출하기 전에 `visited["RED"][r[0]][r[1]] = 0`, `visited["BLUE"][b[0]][b[1]] = 0`을 다시 세팅하지 않았습니다.
- 시작점 값이 `inf`이므로 `visited + 1`도 `inf`가 되어 모든 칸이 계속 `inf`로 유지됩니다.
- 그 결과 `visited[turn][nr][nc] < visited[turn][row][col] + 1` (`inf < inf`)이 항상 `False`가 되어 **방문한 칸을 무한히 재방문하는 무한 재귀**에 빠집니다.

---

### 2. 백트래킹(방문 복원) 누락으로 인한 방문 상태 오염
- `dfs` 내부:
  ```python
  temp = visited[turn][nr][nc]
  visited[turn][nr][nc] = visited[turn][row][col] + 1

  if turn == "BLUE" and [nr, nc] == prev_red:
      continue  # 🚨 치명적: visited[turn][nr][nc]를 temp로 되돌리지 않고 continue!
```
- `visited`를 수정한 후 조건을 만족하지 못해 `continue`할 때 원상복구를 하지 않아, 탐색이 무효화되었음에도 해당 칸이 방문된 상태로 남아 **다른 모든 유효 경로 탐색이 차단**됩니다.

---

### 3. 잘못된 충돌/스왑 판정 (꼬리물기 이동 차단)
- 문제에서 금지하는 크로스 이동은 **빨강 $A \to B$, 파랑 $B \to A$**처럼 서로의 위치를 맞바꾸는 경우뿐입니다.
- 빨강이 $A \to B$로 떠나고 파랑이 $C \to A$로 빨강의 빈자리를 뒤따라가는 것은 **완전히 유효한 이동(꼬리물기)**입니다.
- 하지만 현재 코드는 `if [nr, nc] == prev_red: continue`로 파랑이 빨강의 이전 위치로 가는 것을 무조건 차단하여, 꼬리물기가 필수적인 미로에서 정답을 찾지 못하고 `0`을 출력합니다.

#### 📌 반례
- **입력**:
  ```python
  maze = [
      [1, 0, 5],
      [2, 0, 5],
      [5, 3, 4]
  ]
  ```
- **기대 출력**: `3`
- **사용자 코드 출력**: `0` (정답 경로를 충돌로 오인하여 도달 불가 판정)

---

### 4. 구조적 한계: 번갈아 이동 vs 동시 이동
- 두 수레가 "동시에 1칸씩" 움직이는 문제는 한 수레씩 번갈아 호출하면 다음의 심각한 복잡성이 발생합니다:
  1. 현재 몇 턴이 지났는지 추적하기 어려움 (`max(visited)`는 대기 턴을 정확히 반영하지 못함).
  2. 한 수레가 도착해서 멈춰 있을 때 턴 넘기기 예외 처리가 복잡해짐.
  3. "동일 칸 도착"과 "자리 맞바꾸기" 검사를 한 번에 깔끔하게 처리할 수 없음.

---

## 복잡도

- $N, M$: 격자의 행, 열 크기 (최대 $4 \times 4 = 16$칸)
- **시간 복잡도**: $O(4^K)$ ($K \le 16$, 수레 이동 경로의 최대 길이)
  - 격자 크기가 최대 16칸이고 재방문이 불가능하므로, 탐색 공간이 매우 작아 백트래킹 시 $0.01$초 이내에 통과합니다.
- **공간 복잡도**: $O(N \times M)$ (재귀 스택 깊이 최대 16, $4 \times 4$ 방문 배열)

## 필수 수정

### 왜 "1턴 = 두 수레의 동시 이동"으로 작성해야 하는가?
DFS 함수 1회 호출을 **1턴(빨간 수레 이동 + 파란 수레 이동)**으로 묶으면 문제가 놀라울 정도로 단순해집니다.

1. **상태 관리**:
   - `visited_r[r][c]`, `visited_b[r][c]`를 `True / False` 2차원 리스트로 관리.
   - `dfs(rx, ry, bx, by, turns)` 형태로 현재 턴 수(`turns`)를 인자로 전달.

2. **도착 수레 고정**:
   - 빨간 수레가 이미 도착지에 있다면 이동 후보는 `[(rx, ry)]` (제자리 1개).
   - 아직 도착하지 않았다면 4방향 중 유효한 칸(벽 X, 미방문)을 `r_cands` 리스트에 수집.
   - 파란 수레도 동일하게 `b_cands` 수집.

3. **이중 루프로 동시 이동 검사**:
   ```python
   for nrx, nry in r_cands:
       for nbx, nby in b_cands:
           # 1. 같은 칸으로 동시 이동 불가
           if nrx == nbx and nry == nby:
               continue
           # 2. 서로 자리를 맞바꾸며 이동 불가 (크로스 스왑)
           if (nrx, nry) == (bx, by) and (nbx, nby) == (rx, ry):
               continue

           # 방문 처리 -> 재귀 -> 백트래킹 복원
```

## 선택적 개선 및 완성 코드

```python
def solution(maze):
    n, m = len(maze), len(maze[0])
    
    # 1. 시작 위치 찾기 (1: 빨강 시작, 2: 파랑 시작, 3: 빨강 도착, 4: 파랑 도착, 5: 벽)
    for i in range(n):
        for j in range(m):
            if maze[i][j] == 1:
                rx, ry = i, j
            elif maze[i][j] == 2:
                bx, by = i, j

    visited_r = [[False] * m for _ in range(n)]
    visited_b = [[False] * m for _ in range(n)]
    visited_r[rx][ry] = True
    visited_b[bx][by] = True

    ans = float('inf')
    dr = [-1, 1, 0, 0]
    dc = [0, 0, -1, 1]

    def dfs(rx, ry, bx, by, turns):
        nonlocal ans
        r_end = (maze[rx][ry] == 3)
        b_end = (maze[bx][by] == 4)

        # 두 수레 모두 도착 칸에 도달한 경우
        if r_end and b_end:
            ans = min(ans, turns)
            return

        # 가지치기
        if turns >= ans:
            return

        # 빨간 수레 다음 이동 후보
        r_cands = []
        if r_end:
            r_cands.append((rx, ry))
        else:
            for i in range(4):
                nr, nc = rx + dr[i], ry + dc[i]
                if 0 <= nr < n and 0 <= nc < m and maze[nr][nc] != 5 and not visited_r[nr][nc]:
                    r_cands.append((nr, nc))

        # 파란 수레 다음 이동 후보
        b_cands = []
        if b_end:
            b_cands.append((bx, by))
        else:
            for i in range(4):
                nr, nc = bx + dr[i], by + dc[i]
                if 0 <= nr < n and 0 <= nc < m and maze[nr][nc] != 5 and not visited_b[nr][nc]:
                    b_cands.append((nr, nc))

        # 동시 이동 조합 탐색
        for nrx, nry in r_cands:
            for nbx, nby in b_cands:
                # 조건 1: 같은 칸으로 동시 이동 불가
                if nrx == nbx and nry == nby:
                    continue
                # 조건 2: 자리 바꾸기(스왑) 불가
                if (nrx, nry) == (bx, by) and (nbx, nby) == (rx, ry):
                    continue

                if not r_end: visited_r[nrx][nry] = True
                if not b_end: visited_b[nbx][nby] = True

                dfs(nrx, nry, nbx, nby, turns + 1)

                if not r_end: visited_r[nrx][nry] = False
                if not b_end: visited_b[nbx][nby] = False

    dfs(rx, ry, bx, by, 0)
    return ans if ans != float('inf') else 0
```

## 이 문제에서 읽어야 할 신호

1. **"격자 크기가 최대 $4 \times 4$"** $\rightarrow$ 상태 공간이 매우 작으므로 **완전탐색(DFS 백트래킹)**으로 모든 경로를 탐색해도 시간 초과가 전혀 나지 않는다는 신호입니다.
2. **"매 턴마다 두 수레가 '동시에' 이동한다"** $\rightarrow$ 재귀 함수 1번의 단위를 1개 수레가 아닌 **"1턴(두 수레의 동시 이동)"**으로 설계해야 충돌 조건과 턴 계산이 꼬이지 않습니다.
3. **"도착한 수레는 그 자리에 멈춘다"** $\rightarrow$ 도착한 수레의 이동 후보를 `[현재 위치]` 1개로 고정하고 방문 상태를 유지하면 if-else 분기 없이 깔끔하게 통합됩니다.

- **동시 진행 문제의 함수 단위**: 여러 개체가 동시에 움직일 때는 절대 1개씩 번갈아 재귀를 돌리지 마시고, **각 개체의 이동 후보 리스트를 구한 뒤 `for ... in r_cands:` $\times$ `for ... in b_cands:`로 1턴에 묶어서 전이**시키세요.
- **백트래킹 복원 시점**: `continue`나 `return`을 하기 전에 방문 배열 복원이 누락되지 않았는지 항상 확인하세요.
