## 총평

- 판정: **정답**
- 핵심 이유: 진입 차수가 0인 후보 정점을 찾아 BFS로 연결된 서브그래프들의 정점 수, 간선 수, 사이클 유무를 세어 도넛, 막대, 8자 모양을 정확히 판별했습니다. 생성된 정점이 임의의 정점(중간 또는 끝)에 연결되는 모든 경계 케이스까지 완벽히 커버합니다.

---

## 문제 핵심

1. 세 종류의 그래프가 섞여 있습니다:
   - **도넛 모양**: $N$개 정점, $N$개 간선 (단순 사이클)
   - **막대 모양**: $N$개 정점, $N-1$개 간선 (단방향 경로)
   - **8자 모양**: $2N+1$개 정점, $2N+2$개 간선 (두 사이클이 중심 정점 1개를 공유)
2. **생성된 정점**은 모든 서브그래프의 임의의 정점으로 향하는 단방향 간선만 추가로 가집니다.
3. 구해야 할 것: `[생성된 정점 번호, 도넛 개수, 막대 개수, 8자 개수]`

---

## 현재 접근법 분석

### 1. 생성 정점 후보 탐색
- `indegree == 0`인 모든 정점을 후보군(`candidates`)으로 추출합니다.

### 2. 서브그래프 BFS 탐색 (`check_graph`)
- 간선을 따라가며 중복 간선 방문 시 사이클(`is_cycle = True`)로 판정합니다.
- 탐색 종료 후 방문한 정점 수(`len(node_)`)와 간선 수(`len(edge_)`)를 비교:
  - `node == edge` and `is_cycle`: **도넛 모양**
  - `node + 1 == edge` and `is_cycle`: **8자 모양**
  - 그 외 (`node == edge + 1`): **막대 모양**
- `sum(x[1:])`가 최대인 후보를 생성 정점으로 최종 결정합니다.

---

## 정확성 및 검증

- **임의 진입점 케이스 검증**:
  - 막대 그래프의 중간이나 끝 정점으로 생성 정점의 간선이 들어와도 `len(node_) == len(edge_) + 1` 관계가 유지되어 정확히 막대로 판별됩니다.
  - 8자 그래프의 중심이 아닌 일반 정점으로 진입해도 BFS가 두 개의 루프를 모두 방문하여 `len(node_) + 1 == len(edge_)`가 정확히 성립합니다.
  - 정점 1개짜리 도넛($1 \to 1$), 정점 1개짜리 막대($1$) 등 최소 크기 서브그래프에서도 정상 작동합니다.
- **실행 결과**:
  - 공식 예제 1, 2 모두 통과
  - 무작위 복합 그래프 50개 생성 테스트 100% 일치
  - 간선 $1,000,000$개(최대 제약) 성능 테스트: 약 **0.67초** (제한 시간 5초 이내 통과)

## 복잡도

- $V$: 전체 정점 수 (최대 $1,000,000$), $E$: 전체 간선 수 (최대 $1,000,000$)
- **시간 복잡도**: $O(V + E)$
  - 그래프 인접 리스트 및 차수 계산: $O(V + E)$
  - BFS 탐색: 각 서브그래프의 모든 간선과 정점을 최대 1~2회만 방문하므로 전체 $O(V + E)$
  - 최대 제약(간선 100만 개)에서도 1초 미만으로 안전합니다.
- **공간 복잡도**: $O(V + E)$ (인접 리스트 `graphs`, `indegress`, BFS `visited` 집합)

## 선택적 개선

### 1. BFS 탐색 없이 '정점 차수(Degree)'만으로 10줄 만에 푸는 정석 해법

이 문제는 사실 **그래프를 순회(BFS/DFS)할 필요가 전혀 없는 문제**입니다. 각 모양별 정점들이 가진 **고유한 차수(In-degree / Out-degree) 특성**을 이용하면 훨씬 빠르고 단순해집니다.

| 대상 | In-degree (들어오는 간선) | Out-degree (나가는 간선) | 특징 |
| :--- | :---: | :---: | :--- |
| **생성된 정점** | **$0$** | **$\ge 2$** | 들어오는 간선이 없고 나가는 간선만 2개 이상인 **유일한 정점** |
| **막대 그래프** | - | **$0$** | 막대의 끝 정점은 **나가는 간선이 $0$개** (각 막대마다 정확히 1개 존재) |
| **8자 모양 그래프** | **$\ge 2$** | **$2$** | 8자의 중심 정점은 **나가는 간선이 $2$개, 들어오는 간선이 $2$개 이상** |
| **도넛 모양 그래프** | - | - | **전체 그래프 수($\text{생성 정점의 Out}$) $-$ 막대 수 $-$ 8자 수** |

#### ✨ 차수 카운팅 풀이 (추천 코드)
```python
from collections import defaultdict

def solution(edges):
    in_deg = defaultdict(int)
    out_deg = defaultdict(int)
    nodes = set()
    
    for u, v in edges:
        out_deg[u] += 1
        in_deg[v] += 1
        nodes.add(u)
        nodes.add(v)
        
    created_node = 0
    for node in nodes:
        # 생성된 정점: In == 0 and Out >= 2
        if in_deg[node] == 0 and out_deg[node] >= 2:
            created_node = node
            break
            
    total_graphs = out_deg[created_node]
    stick_count = 0
    eight_count = 0
    
    for node in nodes:
        if node == created_node:
            continue
        # 막대 그래프의 끝점: Out == 0
        if out_deg[node] == 0:
            stick_count += 1
        # 8자 모양의 중심점: Out == 2 and In >= 2
        elif out_deg[node] == 2 and in_deg[node] >= 2:
            eight_count += 1
            
    donut_count = total_graphs - stick_count - eight_count
    return [created_node, donut_count, stick_count, eight_count]
```
- 실행 시간: 0.67초 $\rightarrow$ **0.39초**로 단축 및 코드 길이 대폭 감소.

### 2. 코드 정리 사항
- `check_stick`, `check_eight`: 사용하지 않는 stub 함수는 삭제하는 것이 깔끔합니다.
- `indegress` $\rightarrow$ `indegrees` 오타 수정.
- 생성 정점 조건: `indegress[key] == 0 and len(graphs.get(key, [])) >= 2`를 바로 걸어주면, 막대 그래프의 시작점 후보에 대해 불필요하게 BFS를 돌리는 낭비를 막을 수 있습니다.

## 이 문제에서 읽어야 할 신호

1. **"정점/간선 수가 최대 1,000,000개"** $\rightarrow$ $O(V + E)$ 선형 시간 알고리즘이어야 함.
2. **"도넛, 막대, 8자 등 모양이 정형화된 그래프 판별"** $\rightarrow$ 복잡하게 순회하기 전에 **각 모양의 '특이 정점(출구, 중심점 등)의 차수'**를 먼저 분석하기!
3. **"전체 개수 - (A 개수 + B 개수) = C 개수"** $\rightarrow$ 도넛은 특징을 잡기 까다로우므로 여집합으로 계산하기!
