## 총평

- 판정: **조건부 정답 (입력 파싱 버그)**
- 핵심 이유: DP 점화식 및 양쪽 가장자리/중간 분기 처리는 $O(N^2)$으로 완벽합니다. 다만 입력을 받을 때 `if len(m) > 1:` 조건으로 인해 $N=1$이거나 문자열 공백 처리에 따라 `arr[0]`이 리스트가 아닌 단일 정수(`int`)로 저장되어 `TypeError`가 발생할 수 있습니다.

---

## 문제 핵심

- 정수 삼각형의 꼭대기($i=0$)에서 시작하여 아래 칸으로 내려오면서 거쳐간 숫자의 합 중 최댓값을 구합니다.
- 아래층으로 내려갈 때는 **대각선 왼쪽($j-1$)** 또는 **대각선 오른쪽($j$)** 위치로만 이동할 수 있습니다.
- 삼각형의 크기 $N \le 500$이므로 모든 경로를 탐색하는 완전 탐색($2^{500}$)은 불가능하며, $O(N^2)$의 **동적 계획법(DP)**으로 풀어야 합니다.

---

## 현재 접근법 분석

1. **입력 처리**:
   - `arr`에 각 층의 숫자들을 2차원 리스트 형태로 저장합니다.
2. **DP 상태 전이 (Top-Down 누적)**:
   - 위층($i-1$)에서 아래층($i$)으로 내려가며 각 위치 $j$에 대해:
     - **맨 왼쪽 ($j = 0$)**: 바로 위 오른쪽(`arr[i-1][0]`)에서만 올 수 있음 $\rightarrow$ `arr[i][j] += arr[i-1][j]`
     - **맨 오른쪽 ($j = m - 1$)**: 바로 위 왼쪽(`arr[i-1][j-1]`)에서만 올 수 있음 $\rightarrow$ `arr[i][j] += arr[i-1][j-1]`
     - **중간 ($0 < j < m - 1$)**: 위쪽 두 경로 중 최댓값을 선택 $\rightarrow$ `arr[i][j] += max(arr[i-1][j], arr[i-1][j-1])`
3. 마지막 층(`arr[-1]`)에서 가장 큰 값을 찾아 반환합니다.

---

## 정확성 및 반례

### ⚠️ 필수 수정이 필요한 입력 파싱 버그
현재 코드의 20~25번 줄:
```python
m = input()
if len(m) > 1:
    arr.append([x for x in map(int, m.split())])
else:
    arr.append(int(m))
```

- **문제점**:
  1. $N=1$일 때 `m = "7"`이면 `len(m) == 1`이 되어 `arr`에 `[7]`이 아닌 정수 `7`이 들어갑니다.
     이후 `return max(arr[-1])`에서 `max(7)`이 실행되어 **`TypeError: 'int' object is not iterable`** 에러가 발생합니다.
  2. $N \ge 2$일 때도 첫 줄에 공백/개행이 없거나 한 자리 숫자가 들어오면 `arr[0]`이 정수가 되어, 다음 루프에서 `arr[0][0]` 참조 시 **`TypeError: 'int' object is not subscriptable`**이 발생합니다.
- **해결책**:
  - `list(map(int, input().split()))`은 숫자가 1개든 여러 개든 항상 리스트(`[7]`, `[3, 8]`)로 감싸주므로 `if-else` 분기 없이 한 줄로 처리해야 합니다.

---

## 복잡도

- $N$: 삼각형의 크기 ($1 \le N \le 500$)
- 전체 원소 개수: $1 + 2 + 3 + \dots + N = \frac{N(N+1)}{2} \approx 125,250$개
- **시간 복잡도**: $O(N^2)$
  - 모든 칸을 정확히 한 번씩만 방문하여 덧셈/비교 연산을 수행하므로 약 $1.25 \times 10^5$번 연산 ($0.01$초 이내 완료).
- **공간 복잡도**: $O(N^2)$
  - 입력 배열 `arr` 자체에 값을 누적(In-place)하므로 추가 메모리 없이 최적입니다.

## 필수 수정

입력 파싱부를 모든 층이 일관되게 2차원 리스트가 되도록 수정합니다.

```python
# 수정 전
arr = []
for _ in range(n):
    m = input()
    if len(m) > 1:
        arr.append([x for x in map(int, m.split())])
    else:
        arr.append(int(m))

# 수정 후 (한 줄로 깔끔하게)
arr = [list(map(int, input().split())) for _ in range(n)]
```

## 선택적 개선: 바닥에서 올라오는 역방향 DP (Bottom-Up)

현재 풀이(위 $\to$ 아래)는 양쪽 끝 가장자리($j=0$, $j=m-1$)를 예외 처리해야 합니다.
반대로 **바닥($N-2$)에서 꼭대기($0$)로 거꾸로 올라가면** 예외 분기가 완전히 사라져 코드가 훨씬 우아해집니다.

```python
def solution_bottom_up():
    n = int(input())
    arr = [list(map(int, input().split())) for _ in range(n)]
    
    # 바닥 바로 위층(n-2)부터 꼭대기(0)까지 역순 진행
    for i in range(n - 2, -1, -1):
        for j in range(len(arr[i])):
            # 아래층의 왼쪽(j), 오른쪽(j+1) 중 큰 값을 현재 칸에 더함
            arr[i][j] += max(arr[i + 1][j], arr[i + 1][j + 1])
            
    # 최종 정답은 꼭대기에 모임
    return arr[0][0]
```
- **장점**:
  1. $j=0, j=m-1$ 같은 `if-elif-else` 가장자리 분기가 불필요 (항상 아래에 2개의 자식이 존재함).
  2. 마지막에 `max(arr[-1])`를 찾을 필요 없이 `arr[0][0]` 하나만 반환하면 끝!

## 추천 정리 코드 (정방향 최적화)

```python
import sys

input = sys.stdin.readline

def solution():
    n = int(input())
    arr = [list(map(int, input().split())) for _ in range(n)]

    for i in range(1, n):
        for j in range(i + 1):
            if j == 0:
                arr[i][j] += arr[i - 1][j]
            elif j == i:
                arr[i][j] += arr[i - 1][j - 1]
            else:
                arr[i][j] += max(arr[i - 1][j], arr[i - 1][j - 1])

    return max(arr[-1])

if __name__ == '__main__':
    print(solution())
```

## 이 문제에서 읽어야 할 신호

1. **"삼각형이나 트리 구조에서 아래로 내려가며 누적 최대합"**
   - $\rightarrow$ 이전 층의 결과가 다음 층에 그대로 재사용되는 **전형적인 층별(Level) DP**입니다.
2. **"위에서 아래로 내려가는 경로 vs 아래에서 위로 올라가는 경로"**
   - $\rightarrow$ 둘 다 결과는 같지만, **바닥에서 위로 올라오면 분기문(Boundary Check)이 사라져** 구현이 훨씬 간단해진다는 점을 기억해 두세요!
