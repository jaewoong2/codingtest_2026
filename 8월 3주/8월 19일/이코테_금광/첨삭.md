## 총평

- 판정: **정답**
- 핵심 이유: 열(`col`) 단위로 전진하며 직전 열의 위/가운데/아래 세 방향 중 최댓값을 취해 누적하는 2차원 DP 점화식을 매우 깔끔하고 정확하게 작성했습니다. $N=1, M=1$ 등의 경계 조건도 완벽하게 처리됩니다.

---

## 문제 핵심

- $N \times M$ 크기의 격자에서 첫 번째 열(어느 행이든 가능)에서 출발하여 매번 **오른쪽 위 / 오른쪽 / 오른쪽 아래** 세 방향 중 하나로 이동하며 $M$번째 열까지 도달합니다.
- 이동 경로에 있는 금의 합의 최댓값을 구해야 합니다.
- **방향성**: 항상 열 번호가 $1$씩 증가하므로, 사이클이 없는 전형적인 **격자 경로 DP** 문제입니다.

---

## 현재 접근법

1. $1$차원 배열로 입력되는 금광 데이터를 $N \times M$ 2차원 배열 `maps`로 변환하고, 첫 번째 열을 `dp[i][0] = maps[i][0]`으로 초기화합니다.
2. `col`을 $1$부터 $M-1$까지 순회하며, 각 행 `row`에 대해 직전 열의 세 후보를 비교합니다:
   - 왼쪽 가운데: `dp[row][col - 1]`
   - 왼쪽 위: `dp[row - 1][col - 1]` (인덱스 $0 \le row - 1$ 체크)
   - 왼쪽 아래: `dp[row + 1][col - 1]` (인덱스 $row + 1 < n$ 체크)
3. 세 값 중 최댓값과 현재 칸의 금(`maps[row][col]`)을 더해 `dp[row][col]`에 기록합니다.
4. 마지막 열(`dp[row][-1]`) 중 최댓값을 정답으로 취합니다.

---

## 정확성 및 검증

- **상태 전이 검증**:
  $$\text{dp}[r][c] = \text{maps}[r][c] + \max(\text{dp}[r-1][c-1], \text{dp}[r][c-1], \text{dp}[r+1][c-1])$$
  열이 증가하는 순서대로 계산되므로 이전 열의 최적해가 항상 완전히 계산되어 있어 DP의 최적 부분 구조(Optimal Substructure)를 만족합니다.
- **경계 조건 테스트**:
  - $N=1, M=1$: 루프를 타지 않고 `dp[0][0]` 값이 바로 반환됨 $\rightarrow$ 정상 동작
  - $N=1, M>1$: 위/아래 이동이 차단되어 직선 이동만 누적 $\rightarrow$ 정상 동작
  - $N>1, M=1$: 첫 열의 원소 중 최댓값 반환 $\rightarrow$ 정상 동작
- **실행 결과**:
  - 예제 1, 2 모두 통과 (`19`, `16`)
  - 엣지 케이스 포함 100% 일치

---

## 복잡도

- $T$: 테스트 케이스 수 ($T \le 1,000$)
- $N, M$: 행과 열의 크기 ($1 \le N, M \le 20$)
- **시간 복잡도**: $O(T \times N \times M)$
  - 케이스당 최대 $20 \times 20 = 400$번 연산, $T=1000$이어도 약 $4 \times 10^5$번 연산 ($0.05$초 이내 완료).
- **공간 복잡도**: $O(N \times M)$ (`maps` 및 `dp` 테이블)

## 선택적 개선

1. **불필요한 import 정리**:
   - 맨 첫 줄의 `from re import I`는 사용되지 않으므로 삭제합니다. (IDE 자동 임포트 실수 방지)
2. **2차원 배열 입력 파싱 간소화**:
   - `maps`를 미리 0으로 채우고 슬라이싱하는 대신, 리스트 컴프리헨션으로 한 줄로 생성할 수 있습니다.
   ```python
   # 개선 전
   maps = [[0 for _ in range(m)] for _ in range(n)]
   start = 0
   for i in range(n):
       maps[i] = numbers[start : start + m]
       start += m

   # 개선 후
   maps = [numbers[i * m : (i + 1) * m] for i in range(n)]
   ```
3. **In-place DP (공간 절약)**:
   - 원본 `maps` 값을 유지할 필요가 없다면 `dp` 배열을 따로 만들지 않고 `maps` 배열 자체에 누적 최댓값을 갱신하여 메모리를 아낄 수 있습니다.
4. **온라인 저지 제출 시 출력 형식**:
   - 리스트 전체를 한 번에 `print([19, 16])` 하는 것보다 각 테스트 케이스마다 `print(answer)`를 출력하는 것이 일반적인 채점 환경 형식에 맞습니다.

## 추천 정리 코드

```python
import sys

input = sys.stdin.readline

def solve():
    T = int(input())
    for _ in range(T):
        n, m = map(int, input().split())
        numbers = list(map(int, input().split()))
        
        # n x m 2차원 DP 테이블 초기화
        dp = [numbers[i * m : (i + 1) * m] for i in range(n)]
        
        # 열(col) 단위로 이동하며 DP 갱신
        for col in range(1, m):
            for row in range(n):
                left_up = dp[row - 1][col - 1] if row > 0 else 0
                left_mid = dp[row][col - 1]
                left_down = dp[row + 1][col - 1] if row < n - 1 else 0
                
                dp[row][col] += max(left_up, left_mid, left_down)
                
        print(max(dp[row][m - 1] for row in range(n)))

if __name__ == '__main__':
    solve()
```

## 이 문제에서 읽어야 할 신호

1. **"격자에서 한 방향(오른쪽)으로만 전진하며 최대/최소 비용을 구한다"**
   - $\rightarrow$ 이전 상태로 되돌아가지 않으므로 **열(col) 기준 순차 DP**의 전형적인 신호입니다.
2. **"특정 칸 $(r, c)$에 도달할 수 있는 이전 칸이 한정되어 있다"**
   - $\rightarrow$ 도달 가능한 이전 칸들의 최적값 중 최댓값을 취해 현재 칸의 값을 더하는 점화식을 세웁니다.
