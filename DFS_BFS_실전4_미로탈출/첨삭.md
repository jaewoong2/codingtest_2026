# DFS/BFS 실전 4. 미로 탈출 - 2차 풀이 첨삭

## 총평
- **판정**: 조건부 정답 / 오답 (작은 미로에서는 통과하나 입력 크기가 커지면 **시간 초과 / 메모리 초과** 발생)
- **핵심 이유**: `maps[nr][nc] = maps[row][col] + 1` 형태로 이전 노드 거리 + 1을 누적하는 BFS 핵심 로직을 훌륭하게 적용하셨습니다! 다만 방문 조건식 `0 < maps[nr][nc] <= maps[row][col] + 1`로 인해 이미 최단 거리가 확정되어 지나온 칸들을 더 큰 거리 값으로 재갱신하며 큐에 노드를 중복 푸시(Duplicate Push)하게 됩니다.

---

## 문제 핵심
- **입력**: N x M 크기의 미로 (2 ≤ N, M ≤ 200)
- **핵심 요구사항**: 가중치가 1로 동일한 미로 그래프에서 최단 거리를 구할 때, **"한 번 방문하여 최단 거리가 결정된 노드는 다시 큐에 넣지 않는다"**는 BFS의 불변식을 지켜야 합니다.

---

## 현재 접근법 (수정하신 코드 분석)
- `maps[nr][nc] = maps[row][col] + 1` 로직으로 각 칸까지의 최단 거리를 기록함.
- `row == N - 1 and col == M - 1` 일 때 `maps[row][col]`을 반환하는 종료 조건이 매우 깔끔하게 반영됨.
- 이동 조건으로 `0 < maps[nr][nc] <= maps[row][col] + 1`을 검사함.

---

## 정확성 및 반례

### 시도하신 코드의 잘한 점 👍
- 전역 `distance` 변수를 지우고, `maps` 배열 자체에 `+1`씩 거리를 저장하여 반환하는 BFS 최단 거리의 핵심 구조를 정확히 파악하여 적용하셨습니다!

### 보완점: 조건식 `0 < maps[nr][nc] <= maps[row][col] + 1`의 문제
- `maps[nr][nc]`의 초기 상태는 길인 경우 `1`, 벽인 경우 `0`입니다.
- BFS는 **처음 방문하는 길(`maps[nr][nc] == 1`)**만 방문해야 합니다.
- 하지만 현재 작성하신 조건 `maps[nr][nc] <= maps[row][col] + 1`은 다음과 같은 문제를 일으킵니다.
  1. 이미 거리가 `1`로 확정된 시작점 `(0,0)`의 인접 칸 `(1,0)`(거리 `2`)에서 다시 `(0,0)`을 바라볼 때, `1 <= 2 + 1` (True)가 성립합니다.
  2. 따라서 `(0,0)`의 거리가 `3`으로 덮어씌워지고 **큐에 또 들어갑니다.**
  3. 이렇게 이미 지나온 칸들이 계속 거리가 부풀려지며 큐에 중복 삽입되는 현상(큐 팽창)이 발생합니다.

### 실제 3x3 미로 테스트 결과
```text
3 3
111
111
111
```
- **정상적인 BFS**: 9개 칸이므로 큐에 정점이 **최대 9번** 들어가고 탐색 종료.
- **수정하신 코드**: 큐에 노드가 무려 **73번** 들락날락거린 후 종료 (`Result: 5`는 나오지만 시간/메모리 낭비 심각).
- 만약 $N=200, M=200$ 크기의 미로라면 큐에 노드가 수십~수백만 번 추가되어 **시간 초과(TLE) / 메모리 초과(MLE)**가 발생합니다.

## 올바른 필수 수정

### 방문 조건 단순화 (`== 1`)
아직 방문하지 않은 길은 항상 `1`의 값을 유지하고 있으므로, 조건문을 다음과 같이 단 한 줄로 수정하시면 완벽합니다!

```python
# 기존 조건
if 0 < maps[nr][nc] <= maps[row][col] + 1:

# 올바른 조건 (괴물이 없는 1이고, 아직 방문하지 않아 값이 1인 경우)
if maps[nr][nc] == 1:
```

## 최종 올바른 정답 코드

```python
import os
import sys
from collections import deque

if os.path.exists(os.path.join(os.path.dirname(__file__), "input.txt")):
    sys.stdin = open(os.path.join(os.path.dirname(__file__), "input.txt"), "r")

input = sys.stdin.readline


def solution():
    N, M = map(int, input().split())
    maps = [[int(x) for x in input().rstrip()] for _ in range(N)]
    moves = [[0, 1], [1, 0], [0, -1], [-1, 0]]

    def bfs(r, c):
        queue = deque([(r, c)])

        while queue:
            row, col = queue.popleft()

            if row == N - 1 and col == M - 1:
                return maps[row][col]

            for dr, dc in moves:
                nr, nc = row + dr, col + dc

                if 0 <= nr < N and 0 <= nc < M:
                    # 아직 방문하지 않은 길(1)인 경우만 큐에 삽입
                    if maps[nr][nc] == 1:
                        maps[nr][nc] = maps[row][col] + 1
                        queue.append((nr, nc))

    return bfs(0, 0)


if __name__ == "__main__":
    result = solution()
    print(result)
```
