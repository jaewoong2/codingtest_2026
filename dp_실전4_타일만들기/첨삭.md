# DP - 실전 4번 타일 만들기 첨삭

## 총평

- 판정: **조건부 정답**
- 타일 배치의 개수에 대한 점화식은 올바르게 구현했습니다.
- 현재 입력 3에서는 실제로 5가 출력됩니다.
- 다만 이 문제가 교재의 바닥 공사 문제처럼 결과를 특정 수로 나눈 나머지를 출력해야 한다면, 현재 코드에는 나머지 연산이 빠져 있어 추가 수정이 필요합니다.
- 가장 어려운 부분인 중복 제거는 방향을 잘 잡았습니다. 다만 dp[i - 2] * (dp[2] - 1)의 의미를 공식을 외우기보다, 마지막 부분의 배치를 직접 분류해서 이해하는 것이 좋습니다.

---

## 1. 문제 핵심

세로 길이가 2이고 가로 길이가 N인 바닥을 타일로 채우는 방법의 수를 구하는 문제입니다.

사용 가능한 타일은 다음과 같습니다.

- 1 x 2 타일
- 2 x 1 타일
- 2 x 2 타일

현재 입력은 다음과 같습니다.

~~~text
3
~~~

가로 길이가 3인 바닥을 채우는 방법의 수는 5이므로 현재 실행 결과 5는 맞습니다.

---

## 2. 현재 풀이의 접근법

현재 코드는 다음 값을 저장합니다.

~~~python
dp[i] = 2 x i 바닥을 채우는 방법의 수
~~~

기본값은 다음과 같습니다.

~~~python
dp[1] = 1
dp[2] = 3
~~~

그리고 다음 점화식을 사용합니다.

~~~python
dp[i] = dp[i - 1] * dp[1] + dp[i - 2] * (dp[2] - 1)
~~~

현재 값들을 대입하면:

~~~text
dp[1] = 1
dp[2] = 3
dp[i] = dp[i - 1] x 1 + dp[i - 2] x 2
~~~

즉, 일반적으로 알고 있는 점화식:

~~~text
dp[i] = dp[i - 1] + 2 x dp[i - 2]
~~~

과 같습니다.

따라서 점화식 자체는 맞습니다.

---

## 3. 작은 경우를 직접 그려보기

점화식을 바로 외우려고 하지 말고, 가로 길이가 작은 경우를 먼저 생각하면 좋습니다.

### 2 x 1 바닥

세로로 세운 타일 하나만 놓을 수 있습니다.

~~~text
dp[1] = 1
~~~

### 2 x 2 바닥

가능한 배치는 3가지입니다.

1. 세로 타일 2개
2. 가로 타일 2개
3. 2 x 2 타일 1개

따라서:

~~~text
dp[2] = 3
~~~

### 2 x 3 바닥

마지막 부분을 기준으로 나눕니다.

#### 마지막 한 칸을 채우는 경우

마지막 한 칸에는 세로 타일 하나만 놓을 수 있습니다.

앞의 2칸을 채우는 방법은 dp[2]가지이므로:

~~~text
dp[2] x 1 = 3
~~~

#### 마지막 두 칸을 채우는 경우

마지막 두 칸을 채우는 방법은 다음 두 가지입니다.

- 가로 타일 2개
- 2 x 2 타일 1개

앞의 한 칸을 채우는 방법은 dp[1]가지이므로:

~~~text
dp[1] x 2 = 2
~~~

따라서:

~~~text
dp[3] = dp[2] + 2 x dp[1]
      = 3 + 2
      = 5
~~~

---

## 4. dp[i - 2] x (dp[2] - 1)의 의미

사용자가 가장 어려워한 부분은 다음 식입니다.

~~~python
dp[i - 2] * (dp[2] - 1)
~~~

먼저 dp[2]는 2 x 2 영역을 채우는 모든 방법의 수입니다.

~~~text
dp[2] = 3
~~~

2 x 2 영역의 세 가지 모양을 다음처럼 생각할 수 있습니다.

~~~text
A. 세로 타일 2개
B. 가로 타일 2개
C. 2 x 2 타일 1개
~~~

그런데 점화식에서는 마지막 부분을 다음 두 그룹으로 나눕니다.

### 그룹 1: 마지막 한 칸을 채우는 경우

마지막 한 칸을 세로 타일로 채웁니다.

앞의 i - 1칸을 채우는 방법은:

~~~text
dp[i - 1] x 1
~~~

여기에는 마지막 두 칸이 세로 타일 2개인 경우도 이미 포함되어 있습니다.

왜냐하면 마지막 한 칸을 세로 타일로 놓고, 그 앞의 i - 1칸을 채우는 과정에서 바로 앞 칸에도 세로 타일이 놓일 수 있기 때문입니다.

### 그룹 2: 마지막 두 칸을 하나의 묶음으로 처리하는 경우

2 x 2 영역의 세 가지 모양 중에서:

- 세로 타일 2개는 그룹 1에서 이미 세어짐
- 가로 타일 2개는 그룹 2에서 세어야 함
- 2 x 2 타일은 그룹 2에서 세어야 함

따라서 그룹 2에서 새롭게 추가할 수 있는 모양은 3개가 아니라 2개입니다.

~~~text
dp[2] - 1 = 3 - 1 = 2
~~~

그래서:

~~~text
dp[i - 2] x (dp[2] - 1)
= dp[i - 2] x 2
~~~

이 됩니다.

중요한 표현은 다음입니다.

> dp[2]에서 1을 빼는 이유는 2 x 2를 채우는 방법 중 세로 타일 2개가 마지막 한 칸을 채우는 경우에 이미 포함되어 있기 때문이다.

단순히 “중복이라서 1을 뺀다”라고 외우기보다, 어떤 배치가 어느 그룹에 들어갔는지를 확인해야 합니다.

---

## 5. 왜 중복이 발생하는가?

dp[i - 1]과 dp[i - 2] x dp[2]를 그냥 더한다고 해보겠습니다.

~~~text
dp[i - 1] + dp[i - 2] x 3
~~~

이 방식은 2 x 2의 세 가지 배치를 모두 추가합니다.

그런데 2 x 2의 세로 타일 2개 배치는 다음 두 방법으로 표현할 수 있습니다.

### 방법 A

마지막 한 칸을 세로 타일로 추가합니다.

~~~text
dp[i - 1] x 1
~~~

### 방법 B

마지막 두 칸을 세로 타일 2개로 채웁니다.

~~~text
dp[i - 2] x 3
~~~

같은 배치가 두 번 세어집니다.

따라서 중복되는 세로 타일 2개 배치를 한 번 제거해야 합니다.

~~~text
dp[i - 1] + dp[i - 2] x 3 - dp[i - 2]
= dp[i - 1] + dp[i - 2] x 2
~~~

이것이 dp[2] - 1을 사용하는 이유입니다.

---

## 6. 실제 문제에서 점화식을 떠올리는 방법

이런 식이 바로 떠오르지 않는 것은 자연스럽습니다.

처음부터 다음 공식을 외우려고 하면 어렵습니다.

~~~text
dp[i] = dp[i - 1] + 2 x dp[i - 2]
~~~

대신 다음 순서로 생각하는 것이 좋습니다.

### 1단계: dp의 의미를 문장으로 적기

~~~text
dp[i] = 2 x i 바닥을 채우는 방법의 수
~~~

### 2단계: 가장 오른쪽을 어떻게 채울지 보기

바닥 전체를 한 번에 보지 말고, 오른쪽 끝만 봅니다.

오른쪽 끝은 크게 두 종류로 나뉩니다.

- 마지막 한 칸으로 끝나는 경우
- 마지막 두 칸으로 끝나는 경우

### 3단계: 마지막 한 칸을 채우는 방법 세기

2 x i 바닥의 마지막 한 칸은 세로 타일 하나로만 채울 수 있습니다.

따라서:

~~~text
dp[i - 1] x 1
~~~

### 4단계: 마지막 두 칸을 채우는 새로운 방법 세기

마지막 두 칸을 채우는 방법 중, 이미 마지막 한 칸의 경우에 포함된 것은 제외합니다.

새롭게 추가되는 방법은:

- 가로 타일 2개
- 2 x 2 타일 1개

총 2가지입니다.

따라서:

~~~text
dp[i - 2] x 2
~~~

### 5단계: 두 그룹을 더하기

~~~text
dp[i] = dp[i - 1] + 2 x dp[i - 2]
~~~

이 과정을 반복하면 됩니다.

## 7. 현재 코드를 기준으로 한 점화식 검증

현재 코드는:

~~~python
dp[i] = (dp[i - 1] * dp[1]) + (dp[i - 2] * (dp[2] - 1))
~~~

입니다.

초기값이:

~~~python
dp[1] = 1
dp[2] = 3
~~~

이므로:

~~~text
dp[i]
= dp[i - 1] x 1 + dp[i - 2] x (3 - 1)
= dp[i - 1] + 2 x dp[i - 2]
~~~

입니다.

따라서 수학적으로는 올바른 점화식입니다.

다만 구현을 읽는 사람 입장에서는 다음 코드가 더 직관적입니다.

~~~python
dp[i] = dp[i - 1] + 2 * dp[i - 2]
~~~

dp[1]과 dp[2]를 곱해서 표현하는 방식은 점화식의 유도 과정을 보여주는 데는 의미가 있지만, 실제 구현에서는 불필요하게 복잡해 보일 수 있습니다.

---

## 8. 현재 코드의 정확성 검토

현재 초기값:

~~~python
dp[0] = 0
dp[1] = 1
dp[2] = 3
~~~

에서 dp[0]은 현재 반복문에서 사용되지 않습니다.

반복문은 다음과 같습니다.

~~~python
for i in range(3, n + 1):
~~~

따라서 n이 1 또는 2인 경우에는 미리 저장된 값을 바로 반환하고, n이 3 이상이면 점화식으로 계산합니다.

타일 배치 문제에서 일반적으로:

~~~text
dp[1] = 1
dp[2] = 3
~~~

은 올바른 초기값입니다.

---

## 9. 계산 예시

초기값:

~~~text
dp[1] = 1
dp[2] = 3
~~~

### dp[3]

~~~text
dp[3] = dp[2] + 2 x dp[1]
      = 3 + 2
      = 5
~~~

### dp[4]

~~~text
dp[4] = dp[3] + 2 x dp[2]
      = 5 + 6
      = 11
~~~

### dp[5]

~~~text
dp[5] = dp[4] + 2 x dp[3]
      = 11 + 10
      = 21
~~~

따라서 결과는:

~~~text
dp[1], dp[2], dp[3], dp[4], dp[5]
= 1, 3, 5, 11, 21
~~~

현재 코드도 이 값을 계산합니다.

## 10. 반례와 테스트 방법

점화식이 맞는지 확인할 때는 작은 N부터 직접 세어보는 것이 좋습니다.

### 최소 입력

~~~text
1
~~~

기대 결과:

~~~text
1
~~~

### 두 칸

~~~text
2
~~~

기대 결과:

~~~text
3
~~~

### 세 칸

~~~text
3
~~~

기대 결과:

~~~text
5
~~~

현재 입력이 바로 이 테스트이며, 실제 출력도 5입니다.

### 네 칸

~~~text
4
~~~

점화식으로:

~~~text
dp[4] = dp[3] + 2 x dp[2]
      = 5 + 6
      = 11
~~~

기대 결과:

~~~text
11
~~~

### 반복해서 계산되는 구조 확인

~~~text
5
~~~

기대 결과:

~~~text
21
~~~

이런 작은 값들을 직접 배치해보면 점화식이 단순한 숫자 규칙이 아니라 타일 배치의 분류에서 나왔다는 점을 확인할 수 있습니다.

## 11. 표준 문제의 나머지 조건 확인

문제 원문이 폴더에 없기 때문에 출력 조건을 코드만으로 확정할 수는 없습니다.

다만 이 문제가 교재의 실전 4번 바닥 공사 문제라면 일반적으로 결과를 796,796으로 나눈 나머지를 출력해야 합니다.

그 조건이라면 현재 코드는 큰 N에서 나머지 처리를 하지 않으므로 조건부 정답입니다.

다음처럼 계산 중간에 나머지를 적용해야 합니다.

~~~python
MOD = 796796

for i in range(3, n + 1):
    dp[i] = (dp[i - 1] + 2 * dp[i - 2]) % MOD
~~~

초기값은 그대로 사용합니다.

~~~python
dp[1] = 1
dp[2] = 3
~~~

나머지 연산을 사용하는 이유는 방법의 수가 N이 커질수록 빠르게 증가하기 때문입니다.

---

## 12. 추천 구현

출력에 나머지 조건이 없다면:

~~~python
def solution():
    n = int(input())

    dp = [0] * (n + 1)
    dp[1] = 1

    if n >= 2:
        dp[2] = 3

    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + 2 * dp[i - 2]

    return dp[n]
~~~

표준 교재 문제처럼 796,796으로 나눈 나머지를 출력해야 한다면:

~~~python
def solution():
    n = int(input())
    MOD = 796796

    dp = [0] * (n + 1)
    dp[1] = 1

    if n >= 2:
        dp[2] = 3

    for i in range(3, n + 1):
        dp[i] = (dp[i - 1] + 2 * dp[i - 2]) % MOD

    return dp[n]
~~~

현재 딕셔너리보다 리스트가 자연스러운 이유는 상태가 1부터 n까지 연속된 정수이기 때문입니다.

---

## 13. 복잡도

N을 바닥의 가로 길이라고 하겠습니다.

각 i에 대해 한 번씩 계산하므로:

~~~text
시간 복잡도: O(N)
~~~

dp 배열에 0부터 N까지 값을 저장하므로:

~~~text
공간 복잡도: O(N)
~~~

이 문제의 입력 크기에서는 충분히 효율적입니다.

---

## 14. 공간을 줄이는 선택적 개선

dp[i]를 계산할 때 필요한 값은 dp[i - 1]과 dp[i - 2]뿐입니다.

따라서 변수 두 개만 사용해서 공간을 O(1)로 줄일 수 있습니다.

~~~python
def solution():
    n = int(input())

    if n == 1:
        return 1
    if n == 2:
        return 3

    prev2 = 1
    prev1 = 3

    for _ in range(3, n + 1):
        current = prev1 + 2 * prev2
        prev2, prev1 = prev1, current

    return prev1
~~~

다만 DP를 처음 공부할 때는 전체 배열을 사용하는 방식이 상태 변화를 확인하기 더 쉽습니다.

## 15. 이 문제에서 읽어야 할 신호

다음 표현이 DP를 떠올리는 신호입니다.

- 2 x N처럼 한 방향으로 길이가 늘어난다.
- 작은 길이의 답을 이용해 큰 길이를 만든다.
- 마지막 타일을 어떻게 놓는지에 따라 경우가 나뉜다.
- 방법의 수를 구한다.

특히 타일 문제에서는 다음 질문을 먼저 해보세요.

> 오른쪽 끝에 놓일 수 있는 타일 또는 타일 묶음은 무엇인가?

이 질문에 답하면 대부분의 점화식이 시작됩니다.

## 16. 실제 문제에서 점화식을 떠올리는 연습법

공식을 바로 떠올리는 것을 목표로 하지 않아도 됩니다.

다음 순서를 연습하면 됩니다.

1. N이 1, 2, 3일 때 직접 그린다.
2. dp[i]가 무엇을 의미하는지 문장으로 적는다.
3. 가장 오른쪽을 채우는 마지막 모양을 나눈다.
4. 각 마지막 모양 앞에 남는 부분의 크기를 확인한다.
5. 같은 배치를 두 그룹에서 세고 있지 않은지 확인한다.
6. 중복이 있다면 그룹을 겹치지 않게 다시 정의한다.
7. 작은 N의 결과가 점화식과 일치하는지 확인한다.

이번 문제에서 핵심은 처음부터 dp[2] - 1을 떠올리는 것이 아닙니다.

먼저:

~~~text
마지막 한 칸을 채우는 경우
+
마지막 두 칸을 채우는 새로운 경우
~~~

로 나누면 됩니다.

그 결과:

~~~text
dp[i] = dp[i - 1] + 2 x dp[i - 2]
~~~

가 자연스럽게 나옵니다.
