# DP - 1로 만들기 첨삭

## 총평

- 판정: **오답**
- 단, X가 2 이상만 보장된다면 현재 코드도 정상적으로 동작합니다.
- 표준 문제 조건처럼 X = 1이 입력으로 가능하다면 초기값 때문에 오답이 됩니다.
- 핵심 알고리즘인 동적 계획법과 점화식의 방향은 올바르게 잡았습니다.

현재 입력 26에 대한 결과는 3입니다.

~~~text
26 → 25 → 5 → 1
~~~

세 번의 연산으로 1을 만들 수 있으므로 예제 결과는 맞습니다.

---

## 1. 문제 핵심

정수 X가 주어졌을 때 다음 연산을 사용할 수 있습니다.

1. X가 5로 나누어떨어지면 5로 나눈다.
2. X가 3으로 나누어떨어지면 3으로 나눈다.
3. X가 2로 나누어떨어지면 2로 나눈다.
4. X에서 1을 뺀다.

목표는 X를 1로 만드는 최소 연산 횟수를 구하는 것입니다.

나눌 수 있다고 해서 항상 나누는 것이 최선은 아닙니다. 현재 숫자에서 가능한 연산의 결과를 모두 비교해야 합니다.

---

## 2. 현재 풀이의 접근법

현재 코드는 작은 숫자부터 정답을 계산하는 바텀업 DP를 사용했습니다.

~~~python
for i in range(2, X + 1):
~~~

results[i]에는 i를 1로 만드는 최소 연산 횟수를 저장하려고 했습니다.

먼저 1을 빼는 경우를 계산합니다.

~~~python
result = results[i - 1] + 1
~~~

그리고 나누어떨어지는 경우에는 나누기 연산도 후보에 추가합니다.

~~~python
if i % 2 == 0:
    result = min(result, results[i // 2] + 1)

if i % 3 == 0:
    result = min(result, results[i // 3] + 1)

if i % 5 == 0:
    result = min(result, results[i // 5] + 1)
~~~

이 접근은 문제 구조에 적합합니다.

---

## 3. DP 상태 정의

이 문제에서는 다음처럼 정의해야 합니다.

~~~text
dp[i] = i를 1로 만드는 최소 연산 횟수
~~~

예를 들면:

~~~text
dp[1] = 0
dp[2] = 1   # 2 → 1
dp[3] = 1   # 3 → 1
dp[4] = 2   # 4 → 2 → 1
dp[5] = 1   # 5 → 1
~~~

현재 코드에는 다음 초기값이 있습니다.

~~~python
results = {0: 0, 1: 1, 2: 1, 3: 1, 5: 1}
~~~

하지만 1에서 이미 목표에 도달했으므로 올바른 초기값은 다음이어야 합니다.

~~~python
dp[1] = 0
~~~

현재 주석에는 X = 1일 때 0이라고 적혀 있지만, 코드에는 1로 저장되어 있어 주석과 구현이 일치하지 않습니다.

---

## 4. 정확성 오류와 반례

### 반례 입력

~~~text
1
~~~

### 기대 출력

~~~text
0
~~~

이미 X가 1이므로 아무 연산도 필요하지 않습니다.

### 현재 코드의 결과

현재 초기값이 다음과 같습니다.

~~~python
results = {0: 0, 1: 1, 2: 1, 3: 1, 5: 1}
~~~

따라서 results[1]을 그대로 반환하여 1을 출력합니다.

표준 문제 조건에서 X = 1이 가능하다면 이 부분 때문에 오답입니다.

---

## 5. 점화식이 성립하는 이유

i에서 1로 가는 첫 번째 연산은 다음 중 하나입니다.

### 1을 빼는 경우

~~~text
i → i - 1
~~~

필요한 연산 횟수는 다음과 같습니다.

~~~python
dp[i - 1] + 1
~~~

### 2로 나누는 경우

i가 2로 나누어떨어질 때만 가능합니다.

~~~python
dp[i // 2] + 1
~~~

### 3으로 나누는 경우

i가 3으로 나누어떨어질 때만 가능합니다.

~~~python
dp[i // 3] + 1
~~~

### 5로 나누는 경우

i가 5로 나누어떨어질 때만 가능합니다.

~~~python
dp[i // 5] + 1
~~~

따라서 전체 점화식은 다음과 같습니다.

~~~python
dp[i] = dp[i - 1] + 1

if i % 2 == 0:
    dp[i] = min(dp[i], dp[i // 2] + 1)

if i % 3 == 0:
    dp[i] = min(dp[i], dp[i // 3] + 1)

if i % 5 == 0:
    dp[i] = min(dp[i], dp[i // 5] + 1)
~~~

현재 상태 i에서 가능한 첫 연산을 모두 확인하고 그중 최솟값을 선택하므로 정답이 됩니다.

---

## 6. 현재 코드의 불필요한 초기화

현재 코드는 다음 값을 미리 넣고 있습니다.

~~~python
results = {0: 0, 1: 1, 2: 1, 3: 1, 5: 1}
~~~

그리고 이미 있는 값은 건너뜁니다.

~~~python
if i in results:
    continue
~~~

이 방식도 X가 2 이상이면 결과가 맞을 수 있지만, 기본 상태를 여러 개 특별 취급해야 해서 점화식의 의미가 흐려집니다.

dp[1] = 0만 정확히 설정한 뒤 2부터 모두 같은 규칙으로 계산하는 것이 더 안전합니다.

예를 들어 i = 5일 때도 별도로 저장하지 않고 다음처럼 계산할 수 있습니다.

~~~python
dp[5] = dp[4] + 1
dp[5] = min(dp[5], dp[1] + 1)
~~~

두 번째 줄에서 5 → 1인 한 번의 연산이 자연스럽게 반영됩니다.

---

## 7. 추천 구현

현재 풀이의 구조를 최대한 유지한 개선 코드입니다.

~~~python
def solution():
    X = int(input())

    # dp[i] = i를 1로 만드는 최소 연산 횟수
    dp = [0] * (X + 1)
    dp[1] = 0

    for i in range(2, X + 1):
        # 1을 빼는 경우
        dp[i] = dp[i - 1] + 1

        # 2로 나누는 경우
        if i % 2 == 0:
            dp[i] = min(dp[i], dp[i // 2] + 1)

        # 3으로 나누는 경우
        if i % 3 == 0:
            dp[i] = min(dp[i], dp[i // 3] + 1)

        # 5로 나누는 경우
        if i % 5 == 0:
            dp[i] = min(dp[i], dp[i // 5] + 1)

    return dp[X]
~~~

## 8. 계산 과정 예시

X = 10인 경우를 일부 계산하면 다음과 같습니다.

~~~text
dp[1] = 0

dp[2] = min(dp[1] + 1) = 1

dp[3] = min(dp[2] + 1, dp[1] + 1) = 1

dp[4] = min(dp[3] + 1, dp[2] + 1) = 2

dp[5] = min(dp[4] + 1, dp[1] + 1) = 1

dp[6] = min(dp[5] + 1, dp[3] + 1, dp[2] + 1) = 2

dp[10] = min(dp[9] + 1, dp[5] + 1, dp[2] + 1) = 2
~~~

실제 경로는 다음과 같습니다.

~~~text
10 → 5 → 1
~~~

## 9. 그리디가 아닌 DP인 이유

이 문제에서 “나눌 수 있으면 무조건 나눈다”라고 생각하면 위험합니다.

현재 숫자에서 당장 가장 많이 줄어드는 연산을 선택하는 것이 항상 전체 최소 횟수를 보장하는지 알 수 없기 때문입니다.

DP는 현재 상태에서 가능한 모든 연산을 확인합니다.

~~~text
현재 숫자에서 가능한 다음 상태를 모두 확인
→ 각 다음 상태의 최소 결과를 재사용
→ 그중 최솟값 선택
~~~

현재 코드의 min 사용은 이 문제의 핵심입니다.

---

## 10. 복잡도

X를 입력값이라고 하겠습니다.

각 i에 대해 다음 연산을 최대 4개 확인합니다.

- i - 1
- i // 2
- i // 3
- i // 5

따라서:

~~~text
시간 복잡도: O(X)
공간 복잡도: O(X)
~~~

현재 딕셔너리 방식도 최악에는 O(X) 공간을 사용합니다.

다만 상태가 1, 2, 3, ..., X처럼 연속된 정수이므로 딕셔너리보다 리스트가 더 자연스럽고 빠릅니다.

## 11. 선택적 개선

### 상태 변수 이름

현재 results보다 dp가 상태의 의미를 더 잘 드러냅니다.

~~~python
dp = [0] * (X + 1)
~~~

### 주석 표현

현재 주석의 “최소 방법의 가지수”라는 표현은 정확하지 않습니다.

이 문제에서 구하는 값은 방법의 개수가 아니라 “최소 연산 횟수”입니다.

### 입력 파일 처리

현재 input.txt가 있으면 해당 파일을 읽도록 작성되어 있습니다. 로컬 테스트에는 편리하지만, 제출용 코드에서는 표준 입력을 직접 사용한다고 생각하는 것이 안전합니다.

## 12. 문제에서 읽어야 할 신호

다음 표현이 보이면 DP를 고려할 수 있습니다.

- 최소 연산 횟수
- 여러 연산 중 하나를 선택
- 같은 숫자에 여러 경로로 도달
- 이전 상태의 결과를 반복해서 사용

이 문제에서는 현재 숫자에서 다음과 같은 더 작은 상태로 이동합니다.

~~~text
X → X - 1
X → X / 2
X → X / 3
X → X / 5
~~~

그리고 큰 문제의 답이 작은 문제의 정답에 의존합니다.

~~~text
dp[i] = 이전 상태의 최소 연산 횟수 + 현재 연산 1회
~~~

## 다음 문제를 위한 체크리스트

1. dp[i]가 정확히 무엇을 의미하는지 한 문장으로 작성하기
2. 가장 작은 상태의 값을 먼저 정하기
3. 현재 상태에서 가능한 이전 상태를 모두 나열하기
4. 각 이전 상태에 현재 연산 1회를 더하기
5. 최소값인지 최대값인지에 따라 min 또는 max 선택하기
6. 필요한 이전 상태가 현재 상태보다 먼저 계산되는지 확인하기
7. X = 1, 나누기가 여러 개 가능한 수, 나누기가 전혀 안 되는 수를 테스트하기

이번 문제의 핵심은 다음입니다.

> dp[i]는 i를 1로 만드는 최소 연산 횟수이며, i에서 갈 수 있는 모든 작은 상태의 정답을 비교해야 한다.
