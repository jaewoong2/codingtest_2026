# [이코테 / 프로그래머스] 자물쇠와 열쇠 풀이 첨삭

## 총평

- **판정**: **정답 (Correct)**
- **핵심 이유**:
  1. 자물쇠의 크기를 $N + 2M$으로 확장하여 열쇠가 걸쳐지는 모든 이동 위치를 안전하게 표현했습니다.
  2. 90도 시계방향 회전 알고리즘(`rotate`)을 정확히 구현했습니다.
  3. 돌기 충돌 시 `1e10`이라는 큰 값을 부여하여 겹침을 방지하고, 원래 자물쇠 영역의 합이 $N^2$이 되는지 검증하는 아이디어가 매우 독창적이고 정답을 보장합니다.

---

## 문제 핵심

- $M \times M$ 크기의 열쇠를 회전 및 이동시켜 $N \times N$ 크기의 자물쇠 홈을 완전히 채워 열 수 있는지 판단해야 합니다.
- **핵심 규칙**:
  - 자물쇠 영역 밖의 열쇠 홈과 돌기는 영향을 주지 않음 (자물쇠 3배 확장 패딩 필요).
  - 자물쇠 영역 내부에서는 돌기-돌기가 부딪히면 안 되고, 홈-홈이 남아있어도 안 됨 (모든 칸이 정확히 1이어야 함).
- **입력 제약**: $N, M \le 20$으로 크기가 매우 작으므로 모든 회전(4가지) 및 이동 위치에 대해 일일이 맞추어 보는 **완전 탐색(Brute Force)**으로 해결 가능합니다.

---

## 현재 접근법 평가

사용자께서 설계하신 접근법은 시뮬레이션 문제의 정석적인 좋은 풀이입니다!

1. **`expand()`**: 자물쇠를 중앙에 두고 사방으로 $M$만큼 공간을 넓혀 크기를 $N + 2M$으로 만듦 (영역 벗어남 허용).
2. **`rotate()`**: 2차원 배열 시계방향 90도 회전 수식 `new_array[i][j] = array[N - 1 - j][i]` 적용.
3. **`move2()`**: 자물쇠 홈(`0`)과 열쇠 돌기(`1`)가 만나면 1, 돌기-돌기 충돌 시 `int(1e10)` 대입.
4. **`move()`**: 원래 자물쇠 $N \times N$ 부분만 잘라내어 총합이 $N^2$ (모든 칸이 1)인지 확인.

---

## 복잡도 분석

- $N$: 자물쇠 크기 (최대 20)
- $M$: 열쇠 크기 (최대 20)
- **시간 복잡도**: $O(4 \times (N + M)^2 \times (M^2 + N^2))$
  - 회전 횟수: 4회
  - 이동 가능한 (행, 열) 위치의 수: 약 $(N + M)^2$ 개
  - 각 위치에서 열쇠 대입 연산($M^2$) 및 자물쇠 검증 연산($N^2$)
  - $N=20, M=20$ 대입 시: $4 \times 40^2 \times (400 + 400) \approx 5,120,000$ (약 512만 회 연산)
  - 파이썬 기준 0.1~0.2초 내로 통과 가능한 안전한 시간 복잡도입니다.
- **공간 복잡도**: $O((N + 2M)^2)$
  - 확장된 2차원 자물쇠 배열을 저장하는 공간입니다.

## 선택적 개선 제안 (가독성 & 효율성)

현재 코드도 완벽히 통과하지만, 아래 소소한 부분을 다듬으면 더욱 깔끔하고 효율적인 코드가 됩니다.

### 1. `move()` 함수에서 정답 발견 시 즉시 리턴 (`return True`)

현재 `break`는 안쪽 `j` 루프만 탈출하고 바깥쪽 `i` 루프는 계속 돕니다. `answer = True` 설정 후 `return True`로 탐색을 즉시 종료하면 실행 시간을 단축할 수 있습니다.

```python
# 기존
if total == real_array_length ** 2:
    answer = True
    break # 안쪽 for문만 탈출함

# 개선
if total == real_array_length ** 2:
    return True # 발견 즉시 탐색 성공 리턴!
```

### 2. 배열 복사 대신 "더했다가(열쇠 대입) 검사하고 다시 빼기(원상복구)" 패턴

매번 `move2`에서 2차원 배열 전체를 카피(`[[x for x in row] for row in lock]`)하고 슬라이싱하는 대신, 원본 자물쇠 배열에 열쇠를 더했다가(1 대입/더하기), 맞는지 검사하고, 다시 빼는(복구) 방식이 2차원 완전탐색의 전형적인 관용적 패턴입니다.

#### 💡 깔끔하게 다듬은 코드 예시

```python
def rotate_90(a):
    n = len(a)
    m = len(a[0])
    result = [[0] * n for _ in range(m)]
    for i in range(n):
        for j in range(m):
            result[j][n - 1 - i] = a[i][j]
    return result

# 자물쇠의 중앙 N x N 영역이 모두 1인지 확인하는 함수
def check(new_lock, n, m):
    for i in range(n):
        for j in range(n):
            if new_lock[m + i][m + j] != 1:
                return False
    return True

def solution(key, lock):
    n, m = len(lock), len(key)
    # 자물쇠 크기를 3배로 확장 (N + 2M)
    new_lock = [[0] * (n + m * 2) for _ in range(n + m * 2)]

    # 중앙에 기존 자물쇠 배치
    for i in range(n):
        for j in range(n):
            new_lock[m + i][m + j] = lock[i][j]

    # 4가지 방향에 대해 확인
    for _ in range(4):
        key = rotate_90(key)
        for x in range(1, n + m):
            for y in range(1, n + m):
                # 열쇠를 자물쇠에 더하기
                for i in range(m):
                    for j in range(m):
                        new_lock[x + i][y + j] += key[i][j]

                # 자물쇠가 맞는지 확인
                if check(new_lock, n, m):
                    return True

                # 열쇠를 다시 빼서 원상복구
                for i in range(m):
                    for j in range(m):
                        new_lock[x + i][y + j] -= key[i][j]

    return False
```

## 이 문제에서 읽어야 할 신호 (구현 팁)

1. **"영역을 벗어나도 된다" + "영역 안에서 딱 맞춰야 한다"**
   - ⭐ **신호**: 2차원 배열 맵을 원래 크기의 3배($N + 2M$)로 넓혀서 중앙에 배치하는 **맵 확장 패딩(Padding) 기법**을 떠올려야 합니다.

2. **"회전과 이동이 가능하다" + $N, M \le 20$**
   - ⭐ **신호**: 제약 조건의 크기가 매우 작으므로 모든 회전(4가지) x 모든 이동 조합을 다 해보는 **완전 탐색(Brute Force)**이 정답입니다.
