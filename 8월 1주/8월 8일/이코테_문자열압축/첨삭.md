# [이코테 / 프로그래머스] 문자열 압축 풀이 첨삭

## 총평

- **판정**: 오답 (`solution()` 기준). 단, `solution2()`는 정답입니다.
- **핵심 이유**: 채점기가 호출하는 `solution()`의 `while True` 문에 종료 조건이 없어 모든 길이 2 이상의 입력에서 무한 루프가 발생합니다.

## 문제 핵심

- 문자열을 `step` 개 단위로 앞에서부터 잘라, 연속해서 같은 조각만 `반복 횟수 + 조각`으로 압축합니다.
- 모든 `step = 1 .. len(s) // 2`를 확인한 뒤 가장 짧은 길이를 구합니다.
- 마지막 자투리가 `step`보다 짧어도 그대로 결과에 포함해야 합니다.
- 표준 문제의 문자열 길이는 1,000 이하이므로 모든 압축 단위를 확인해도 충분합니다.

## 현재 접근법

`solution2()`와 `solution()` 모두 압축 단위를 1부터 반으로 늘려 가며, 현재 조각과 다음 조각을 비교합니다. 접근 자체는 이 문제에 정확합니다.

- `solution2()`는 `range(step, length, step)`로 유한한 반복 범위를 만들고, 루프 후에 마지막 묶음을 처리합니다.
- `solution()`은 인덱스를 직접 옮기지만, 인덱스가 문자열 끝을 넘은 후에도 루프를 멈추지 않습니다.

## 정확성 및 반례

### `solution2()`

정답입니다. 각 `step`에서 `prev`는 현재 압축 중인 조각, `count`는 그 조각의 연속 횟수를 유지합니다. 다른 조각을 만났을 때만 이전 묶음을 확정하고, 루프가 끝난 뒤 마지막 묶음을 한 번 더 추가하므로 빠지거나 중복되는 문자가 없습니다.

### `solution()`

- **입력**: `"aabbaccc"`
- **기대 반환값**: `7`
- **실제 동작**: 1초 제한으로 직접 실행했을 때 종료되지 않아 타임아웃이 발생했습니다.
- **오류 흐름**: 56~57번 줄에서 인덱스는 계속 커지고, 파이썬 슬라이싱은 범위를 넘어가면 `""`를 반환합니다. 이후 `current_word == next_word == ""`가 계속 참이라 `value`만 증가합니다.

## 복잡도

`N = len(s)`라고 하겠습니다.

- `solution2()`의 조각 비교는 모든 단위에 대해 전체적으로 `O(N²)` 시간 안에 수행됩니다.
- 다만 연속한 문자열 `+`는 기존 문자열 복사 비용을 만들 수 있습니다. 보수적으로는 추가 비용이 커질 수 있지만 `N <= 1,000`에서는 제한을 만족합니다.
- 압축 결과를 직접 만드는 현재 구현의 추가 공간은 `O(N)`입니다.
- `solution()`은 종료하지 않으므로 유한한 시간 복잡도를 부여할 수 없습니다.

## 필수 수정

1. 현재 그대 제출한다면 정상 동작하는 `solution2()`를 `solution()`으로 사용하는 것이 가장 간단합니다.
2. `while` 방식을 유지하고 싶다면 `while start < length:`로 바꾸고, 각 현재 조각은 루프 안에서 이미 확정되므로 59~62번 줄의 루프 후 추가 처리는 제거해야 합니다. 종료 조건만 추가하고 후처리를 남기면 마지막 조각을 중복 추가할 수 있습니다.

## 선택적 개선

- 64번 줄의 `print(word, step)`는 디버깅 출력이므로 제출 전 제거하세요.
- 압축 조각을 리스트에 담고 마지막에 `"".join(parts)`를 사용하면 문자열 누적 복사를 피할 수 있습니다.

## 실행 검증

- `solution2()`는 공식 예시 5건과 최소 길이 1 입력을 통과했습니다.
- `a`, `b`로 만든 길이 1~8의 모든 문자열 510건을 독립적인 기준 풀이와 교차 검증했고 모두 일치했습니다.
- 이 검증은 `solution2()`의 짧은 입력에 대한 신뢰를 높이지만, 정당성은 위의 불변식과 제약 검토로 판단했습니다.

## 이 문제에서 읽어야 할 신호

- **“1개 단위부터 잘라 압축”** → 가능한 자르기 단위를 모두 확인하는 완전 탐색
- **“앞에서부터 정해진 길이로 잘라야 함”** → 부분 문자열의 모든 시작점을 고르는 문제가 아님
- **길이가 `step`으로 나누어떨어지지 않음** → 마지막 자투리 처리 확인
