# 이코테 문자열 뒤집기 첨삭

## 수정 후 총평

- **판정: 아직 오답**
- 이전에 지적한 첫 번째 그룹 누락 문제를 보완하려고 `last`를 사용한 방향은 좋습니다.
- 하지만 마지막 그룹을 처리하는 부분에서 `zeros`와 `ones`를 반대로 증가시키고 있어 일부 입력에서 여전히 오답입니다.
- `input()`의 줄바꿈을 제거하지 않아 일반적인 표준 입력에서는 `ValueError`도 발생할 수 있습니다.

## 현재 풀이의 접근법

현재 코드는 인접한 숫자가 달라지는 지점에서 이전 그룹의 개수를 세고, 마지막 그룹을 반복문 뒤에서 처리하려고 합니다.

```python
last = string[0]

for i in range(1, len(string)):
    if last != string[i]:
        if last == 0:
            zeros += 1
        else:
            ones += 1

        last = string[i]
```

이 방식은 연속된 그룹을 세는 올바른 접근입니다. 전환 지점에서 이전 그룹을 세고, 반복문이 끝난 뒤 마지막 그룹을 한 번 세면 됩니다.

## 정확성 및 반례

### 핵심 오류: 마지막 그룹의 카운터가 반대임

현재 코드의 마지막 부분입니다.

```python
if last == 0:
    ones += 1
else:
    zeros += 1
```

`last == 0`이면 마지막 그룹은 0 그룹이므로 `zeros`를 증가시켜야 합니다. 현재 코드는 반대로 `ones`를 증가시키고 있습니다.

올바른 코드는 다음과 같습니다.

```python
if last == 0:
    zeros += 1
else:
    ones += 1
```

### 반례 1: `10`

입력:

```text
10
```

그룹은 다음과 같습니다.

```text
1 | 0
```

0 그룹을 뒤집거나 1 그룹을 뒤집으면 되므로 기대 출력은 `1`입니다.

현재 코드의 실제 흐름:

```text
1 → 0 전환
ones = 1
last = 0
마지막 그룹 처리에서 ones를 다시 증가
zeros = 0, ones = 2
min(zeros, ones) = 0
```

현재 코드의 실제 출력:

```text
0
```

### 반례 2: `01`

입력:

```text
01
```

그룹은 `0 | 1`이므로 기대 출력은 `1`입니다.

현재 코드는 마지막 `1` 그룹을 `zeros`로 잘못 세어 `0`을 반환합니다.

### 반례 3: `111000`

입력:

```text
111000
```

그룹은 다음과 같습니다.

```text
111 | 000
```

0 그룹과 1 그룹이 각각 1개이므로 기대 출력은 `1`입니다.

현재 코드는 마지막 0 그룹을 1 그룹으로 잘못 세어 `0`을 반환합니다.

### 우연히 맞는 입력

```text
0001100
```

현재 코드는 이 입력에서 `1`을 출력합니다. 하지만 마지막 그룹을 반대로 세는 오류가 다른 카운트와 우연히 상쇄된 결과입니다. 일부 테스트가 맞는 것과 로직이 항상 맞는 것은 구분해야 합니다.

## 입력 처리 오류

현재 입력 변환은 다음과 같습니다.

```python
string = [int(x) for x in str(input())]
```

일반적인 표준 입력에서 `input()`은 줄바꿈을 포함할 수 있습니다.

```text
"10\n"
```

이때 `\n`까지 `int()`로 변환하려고 하므로 다음 오류가 발생합니다.

```text
ValueError: invalid literal for int() with base 10: '\n'
```

현재 `input.txt`에 줄바꿈이 없으면 이 문제가 숨겨질 수 있습니다.

다음처럼 입력을 먼저 정리해야 합니다.

```python
string = [int(x) for x in input().strip()]
```

더 좋은 방법은 숫자 리스트를 만들지 않고 문자열의 `'0'`, `'1'`을 직접 비교하는 것입니다.

## 추천 구현

현재 풀이의 구조를 최대한 유지하면 다음과 같습니다.

```python
def solution():
    string = input().strip()

    zeros = 1 if string[0] == '0' else 0
    ones = 1 if string[0] == '1' else 0

    for i in range(1, len(string)):
        if string[i] != string[i - 1]:
            if string[i] == '0':
                zeros += 1
            else:
                ones += 1

    return min(zeros, ones)
```

이 구현은 첫 번째 그룹을 초기값으로 세고, 이후 새로운 그룹이 시작될 때만 카운트를 증가시킵니다.

## 왜 `min(zeros, ones)`인가?

문자열을 모두 0으로 만들려면 1 그룹을 뒤집어야 합니다.

```text
필요한 횟수 = 1 그룹의 개수
```

문자열을 모두 1로 만들려면 0 그룹을 뒤집어야 합니다.

```text
필요한 횟수 = 0 그룹의 개수
```

따라서 두 그룹 수 중 작은 값을 선택합니다.

## 복잡도

문자열 길이를 `N`이라고 하겠습니다.

- 한 번 순회하므로 시간 복잡도는 `O(N)`입니다.
- 현재 리스트 변환 방식은 `O(N)`의 추가 공간을 사용합니다.
- 문자열을 직접 순회하는 추천 구현은 입력을 제외한 추가 공간 `O(1)`입니다.

## 선택적 개선

- 숫자 리스트 대신 문자열을 직접 사용합니다.
- `last`를 별도로 관리하는 방식과 `string[i - 1]`을 비교하는 방식을 하나로 통일합니다.
- `zeros`, `ones`보다 `zero_groups`, `one_groups`라는 이름이 의미를 더 분명하게 보여줍니다.
- `input.txt`가 존재하면 표준 입력보다 해당 파일을 우선해서 읽으므로, 제출 전 표준 입력으로도 테스트합니다.

## 이 문제에서 읽어야 할 신호

- 연속된 구간을 한 번에 뒤집을 수 있습니다.
- 최종 상태는 모두 0 또는 모두 1 중 하나입니다.
- 숫자가 바뀌는 곳에서 새로운 그룹이 시작됩니다.
- 0 그룹과 1 그룹을 각각 센 뒤 더 적은 쪽을 뒤집으면 됩니다.
